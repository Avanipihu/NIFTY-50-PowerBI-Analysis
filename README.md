# NIFTY 50 Market Analysis (2020–2025)

## Overview
Power BI-based analysis of the NIFTY 50 Index covering January 2020
to December 2025.

## Objectives
- Analyse long-term market trends
- Measure volatility and risk
- Analyse trading volume and turnover
- Build an executive KPI dashboard
- Identify relationships between volatility, returns and money flow

## Tools Used
- Power BI
- CSV
- DAX
- Data Visualization

## Dataset
NIFTY 50 daily market data from 2020–2025.

## Power BI Analysis
1. Macro Trend Analysis
2. Volatility & Risk Assessment
3. Volume & Money Flow
4. Executive KPI Dashboard
5. Advanced Insights & Correlation

## Key Metrics
- Average Close
- Maximum High
- Minimum Low
- Total Turnover
- Volatility
- Daily Returns

## Files
- `data/` – Dataset
- `powerbi/` – Power BI dashboard
- `report/` – Project report
- `screenshots/` – Dashboard screenshots
